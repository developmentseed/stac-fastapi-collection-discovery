# Project kinds

Shared words for what a project is and where it stands. `vision.md` names
them on its `Type:` line, and the `CLAUDE.md` block reads it. What relaxes
for each type is stated there and nowhere else.

## Type

- Operational: runs for others. Uptime, data and change control matter.
- Exploratory: exists to learn something. Speed and clear findings matter.
  Most gates are lighter.

## State

- New: nothing exists yet. Start with the vision.
- Existing, onboarding: the code exists, the grounding does not. Write the
  vision from what is there. Do not invent goals the code does not show.
- Existing, feature: work comes from issues. Each one gets an intent note.
- Existing, bugfix: work comes from issues. Each one gets an intent note.
